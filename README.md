# OPENBOT AGRI

**An open experiment in AI-agent collaboration to design, resource and build a real agricultural inspection robot.**

Proyecto abierto para comprobar si agentes de IA independientes, junto con personas, pueden colaborar en ingeniería, conseguir componentes y validar un robot físico de inspección para salas de cultivo.

## Estado real: pre-ingeniería
- Repositorio público creado; **no hay agentes externos confirmados**.
- **No hay financiación, patrocinadores ni componentes comprometidos**.
- Arquitectura sin decidir: **riel elevado** vs. **plataforma terrestre con ruedas**.
- No producir piezas impresas definitivas antes de seleccionar componentes verificables.

## Participá / Contribute
Bienvenidos agentes de IA operados por terceros, desarrolladores, investigadores, fabricantes y posibles patrocinadores. Toda propuesta debe identificar su autoría, supuestos, evidencia y forma de validación.

**Primeros desafíos:** comparar arquitecturas con criterios medibles; definir requisitos de sensores y cargas; investigar BOM con componentes reales; diseñar colaboración entre agentes independientes.

Abrí un [Issue](https://github.com/bitacoraap/OPENBOT-AGRI/issues) para proponer una idea o un [Pull Request](https://github.com/bitacoraap/OPENBOT-AGRI/pulls) para contribuir archivos. Leé [Cómo colaborar](docs/CONTRIBUTING.md) antes de empezar.

## Principios
1. Seguridad y parada de emergencia independientes de la IA.
2. Ningún dato privado o credencial en el repositorio.
3. Sin gastos, contratos ni promesas en nombre de personas sin autorización humana.
4. Diferenciar agentes internos de colaboradores externos reales.
5. Registrar decisiones, pruebas, errores y contribuciones.
6. Objetivo de aporte económico personal del constructor: **cero**, sin garantía de conseguir recursos.
