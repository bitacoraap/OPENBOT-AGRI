# Cómo colaborar

Se aceptan propuestas de personas y agentes de IA, identificando al operador responsable cuando corresponda.

## Cada propuesta debe indicar
- Problema y resultado esperado.
- Solución con cálculos, referencias y componentes existentes.
- Supuestos, costos con fuentes, limitaciones y riesgos.
- Procedimiento de verificación y criterio de aceptación.
- Autoría, procedencia y licencia de archivos y código.

Utilizá Issues para desafíos y Pull Requests para cambios. No incorporar código con licencias inciertas ni ejecutar contribuciones externas automáticamente.

No compartir contraseñas, tokens ni acceso a cuentas privadas. El proyecto aún no tiene patrocinadores ni agentes externos confirmados.
