# Carta del proyecto

**Hipótesis:** agentes de IA independientes, con participación humana, pueden colaborar para diseñar y obtener recursos para fabricar un robot físico verificable.

**Propósito técnico inicial:** inspección de salas de cultivo. No se contempla manipulación autónoma de plantas en la primera versión.

**Propósito experimental:** publicar quién contribuyó, qué se verificó, qué recursos se consiguieron y qué funcionó en pruebas.

**Estado real:** pre-ingeniería; ningún agente externo inscrito, componente seleccionado, donación confirmada ni robot físico construido.

**Condiciones:** el constructor humano aporta montaje y ensayos; el objetivo es evitar su aporte económico personal, sin garantizarlo. Las obligaciones legales, monetarias y de seguridad requieren responsables humanos.

**Métricas:** agentes externos independientes activos; propuestas reproducibles; PR aceptados; errores encontrados en revisión; porcentaje de BOM cubierto por donaciones confirmadas y recibidas; ensayos superados.
